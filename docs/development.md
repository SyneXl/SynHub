# Разработка

## Проверка

Из корня репозитория:

```sh
python tools/fetch_luau.py
python tools/build.py
python tools/check.py
```

Используется официальный Luau 0.744. Загрузка инструментария проверяется по закреплённой контрольной сумме. Дополнительные пакеты для сборки не нужны.

`check.py` проверяет соответствие сборки исходникам, компиляцию всех модулей и интерфейса, 15 сценариев ядра и 12 сценариев интеграции. Интеграционные проверки запускают общий загрузчик с полным словарём, имитацией игры и виджетов интерфейса. Они проверяют повторный запуск, очистку обработчиков, сетевые ошибки, сохранения, смену скорости и замену отклонённого слова. Эти проверки не заменяют проверку меню в настоящем клиенте.

GitHub Actions выполняет те же проверки для каждого pull request и изменения `main`.

После публикации можно проверить фактическое содержимое GitHub:

```sh
python tools/check.py --remote
```

## Обновление игры

1. Изменить модули в `src/games/<игра>/`.
2. Обновить `version` игры в `games.json`.
3. Выполнить сборку и проверки.
4. Включить в коммит исходники, новый файл в `releases/`, новые ресурсы и `manifest.json`.

Не редактировать и не удалять выпущенные файлы с хешами. Для отката достаточно восстановить нужное описание версии в `manifest.json`; для следующей обычной сборки следует также восстановить соответствующие исходники и реестр.

## Новая игра

Добавить `src/games/<имя>/init.luau`, экспортирующий `start(context)`, и описание в `games.json`. Указать уникальные `placeIds`, имя, версию, входной модуль и необходимые ресурсы. Импорты имеют вид `require("shared/scope")` и разрешаются сборкой внутри `src/`.

Драйвер, интерфейс и правила новой игры располагаются в её папке. Общий загрузчик менять не требуется. Сборка отклоняет циклические зависимости и повторяющиеся `PlaceId`.

## Словарь

`data/dictionaries/russian-nouns.txt` содержит 39 920 существительных в порядке частотности. Метаданные подготовки находятся рядом. При замене словаря сохранить сведения об источниках и условиях использования в `THIRD_PARTY.md` и `licenses/`.
