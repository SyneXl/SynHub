# Архитектура

```text
loader.luau                  Общий загрузчик
games.json                   Реестр игр для сборки
manifest.json                Текущие версии и пути файлов
src/
  shared/scope.luau          Завершение сессии и отключение обработчиков
  games/slova/
    init.luau               Запуск, события и жизненный цикл
    core.luau               Подбор слов и состояние автобоя
    driver.luau             Подключение к интерфейсу игры
    interface.luau          Меню WindUI
    config.luau             Чтение и проверка настроек
    storage.luau            Сохранение и перенос старых данных
data/dictionaries/          Словарь и сведения о его подготовке
vendor/                     Закреплённые сторонние компоненты
releases/<игра>/<hash>.luau  Собранные модули игры
assets/<имя>/<hash>.*        Данные и интерфейс для конкретной сборки
tests/                      Проверки ядра и загрузчика
tools/                      Сборка и проверка
```

## Загрузка

Загрузчик читает `manifest.json`, находит игру по `PlaceId` и получает готовую сборку с её данными. Исходные модули объединяются заранее: отдельных сетевых запросов для каждого `require` нет.

Имена файлов сборки и ресурсов содержат SHA-256 содержимого. Сборка проверяет хеши, а загрузчик проверяет размер полученных файлов. Проверка размера в клиенте не является проверкой подлинности. Ресурсы уже запущенной сессии остаются в памяти и повторно не скачиваются при перезапуске той же версии.

Файлы с хешами неизменяемы. При обновлении создаются новые файлы и обновляется манифест одним коммитом. Старые файлы сохраняются, чтобы ранее закешированный манифест продолжал работать. Благодаря этому меню, код и словарь относятся к одной сборке.

Загрузчик сначала скачивает ресурсы и проверяет, что код компилируется. Только затем завершает текущую сессию. Ошибка загрузки оставляет прежнюю сессию работающей. Незавершённый запуск новой игры отключает созданные обработчики и удаляет частичный интерфейс.

## Модуль игры

Каждый модуль экспортирует `start(context)`. Результат — объект с `alive` и методом `Destroy()`. Все соединения и действия завершения регистрируются в `Scope`. Выгрузка останавливает печать, сохраняет данные, отключает события и удаляет меню.

`context` содержит описание версии, уже загруженные ресурсы, доступные функции среды и callback выгрузки. Ядро автобоя не обращается к интерфейсу или сервисам игры: ввод и события передаются через драйвер.

При изменении интерфейса игры обычно достаточно обновить `driver.luau`. Подбор слов, обработка отклонения и интерфейс при этом остаются отдельными модулями.
