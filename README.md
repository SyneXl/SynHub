# SynHub

By SyneX

## Запуск

```luau
loadstring(game:HttpGet("https://raw.githubusercontent.com/SyneXl/SynHub/refs/heads/main/loader.luau"))()
```

Загрузчик сам определяет игру и открывает нужный интерфейс. Повторный запуск заменяет предыдущую сессию.

## Игры

| Игра | Возможности |
|---|---|
| [Игра в Слова](https://www.roblox.com/games/71106427459865) | Автобой, частотный русский словарь, ручной выбор слова, фильтр последней буквы, история и настройки печати |

Автобой запускается выключенным. В своём ходу он вводит слово со второй буквы, отправляет его и заменяет отклонённое слово. Начальная буква определяется автоматически. При вводе текста в меню или чате печать приостанавливается.

Настройки и история сохраняются в `SynHub/slova/state.json`, если среда запуска поддерживает работу с файлами. При первом запуске подхватываются сохранения из `Slova/state.json`.
